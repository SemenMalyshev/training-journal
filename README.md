# Тренировка

Статический сайт для двух людей на отдельных телефонах. Каждый браузер хранит собственные тренировки локально; аккаунта, сервера и автоматической синхронизации нет.

## Возможности

- Предустановки «Толкание», «Тяга», «Ноги» и свободная тренировка. Все предложения можно заменить или убрать.
- В каждой предустановке предлагается упражнение на пресс.
- Бег: цель, фактическая дистанция, время и рассчитанный темп.
- Запись подходов, веса, повторений, запаса чистых повторений, дискомфорта и заметок.
- Подсказки по истории и осторожные предложения по прогрессии нагрузки. Сайт не меняет веса автоматически.
- Автосохранение черновика, история, исправление записей, PDF одной тренировки и JSON-копия всей истории.
- Работа без сети после первого открытия на HTTPS-сайте благодаря service worker.

## Использование

Откройте `index.html` на локальном сервере или разместите папку на GitHub Pages. Для проверки на компьютере можно запустить в этой папке `node serve.js` и открыть `http://127.0.0.1:8000/`. Открытие через `file://` не подходит для надёжной проверки локального хранилища или работы без сети.

Для установки на телефон откройте опубликованный сайт через HTTPS и добавьте его на домашний экран. На каждом телефоне укажите своё имя в настройках. Периодически скачивайте JSON-копию; PDF предназначен для чтения и отправки и не восстанавливает историю внутри сайта.

## Публикация позже

Файлы сайта находятся в корне Git-репозитория и готовы к публикации через GitHub Pages из ветки `main`, папка `/`. В репозитории нет пользовательских тренировок: записи находятся только в браузере. Публикация пока не настроена.
