# Тренировка

Статический сайт для двух людей на отдельных телефонах. Каждый браузер хранит собственные тренировки локально; аккаунта, сервера и автоматической синхронизации нет.

Сайт: https://semenmalyshev.github.io/training-journal/

## Возможности

- Предустановки «Толкание», «Тяга», «Ноги» и свободная тренировка. Все предложения можно заменить или убрать.
- В каждой предустановке предлагается упражнение на пресс.
- Бег: цель, фактическая дистанция, время (отдельные поля минут и секунд) и рассчитанный темп.
- Необязательная длительность занятия ограничивает число рекомендованных упражнений. Оценка приблизительная, список можно менять.
- Порядок упражнений меняется кнопками «Выше» и «Ниже». В тренировках на толкание и тягу ноги предлагаются после верхней части тела.
- Запись разминочных и рабочих подходов, веса, повторений, запаса чистых повторений, дискомфорта и заметок. Вес гантелей указывается за одну гантель.
- Разовая передача плана через QR-код или ссылку. Передаются вид тренировки, дата, длительность, упражнения, их порядок и типы подходов; личная история, результаты и веса не передаются. Для получения QR откройте ссылку обычной камерой телефона. Если ссылка открылась в другом браузере, вставьте её через кнопку на сайте. Повторные изменения требуют нового кода.
- Подсказки по истории и осторожные предложения по прогрессии нагрузки. Сайт не меняет веса автоматически.
- Автосохранение черновика, история, исправление записей, PDF одной тренировки и JSON-копия всей истории.
- Настройки текста (100/125/150%), размера кнопок и полей, светлой, тёмной и контрастной темы. Они сохраняются на каждом телефоне отдельно и применяются к новым PDF: размер элементов меняет отступы и расстояния между блоками.
- Работа без сети после первого открытия на HTTPS-сайте благодаря service worker.

## Использование

Откройте `index.html` на локальном сервере или разместите папку на GitHub Pages. Для проверки на компьютере можно запустить в этой папке `node serve.js` и открыть `http://127.0.0.1:8000/`. Открытие через `file://` не подходит для надёжной проверки локального хранилища или работы без сети.

Для установки на телефон откройте опубликованный сайт через HTTPS и добавьте его на домашний экран. На каждом телефоне укажите своё имя в настройках. Периодически скачивайте JSON-копию; PDF предназначен для чтения и отправки и не восстанавливает историю внутри сайта.

## Публикация

GitHub Pages публикует файлы из ветки `main`, папка `/`. В репозитории нет пользовательских тренировок: записи находятся только в браузере. Сайт доступен всем, у кого есть ссылка; он не требует входа в GitHub.
